# Office printer: Jobs stuck or not printing (SAMPLE ARTICLE)

Applies to: office printers on the corporate network. This is sample content for testing.

## Steps to resolve

1. **Check the printer display** for paper jams or empty trays and clear them.
2. **Clear the print queue.** Windows: Settings > Printers > Open queue > Cancel all.
   macOS: System Settings > Printers > Open Print Queue > delete the jobs.
3. **Re-add the printer** using its name on the label (for example, PRN-3F-EAST).
4. **Print a test page.** If it still fails, note the printer name and any error code.

## Additional notes

- Printers that show "Offline" for more than 15 minutes are an Incident Request.
