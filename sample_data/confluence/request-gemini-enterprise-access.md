# Gemini Enterprise: Request access for a user (SAMPLE ARTICLE)

Applies to: managers requesting Gemini Enterprise access for themselves or their team.
This is sample content for testing.

## Steps to resolve

1. **Confirm the user has a company account.** Contractors need an active account in the
   directory before access can be granted.
2. **Raise a Service Request.** Include each user's full name and email, their team, and
   which agents they need.
3. **Manager approval.** The requester's manager approves the ticket. Requests without
   approval are closed after five working days.
4. **Access is granted** by adding the user to the "Gemini Enterprise Users" group. It can
   take up to one hour to apply.

## Additional notes

- One ticket can cover several users; list all of them in the description.
- Access to individual agents may need a separate approval from the agent owner.
